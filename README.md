# Телеграм-бот для упрощения процесса учебы в СПО и ВУЗах.

Бот нацелен на встраивание в учебное заведение, для организации и автоматизации процессов внутри. Он ожидает, что в учебном заведении учащиеся распределены на группы.

**Возможности:**

- Управление домашним заданием в группе (прикрепление фото и файлов), возможность отмечать выполненные задания;
- Просмотр расписания группы с учетом четной и нечетной недели (\* и \*\* звездочки);
- Web просмотр ЛК учебного заведения;
- Опросы присутствия;

## Запуск

### Настройка

Переименуйте `example.env` -> `.env` и впишите туда свои данные.

### Запуск через docker/podman

Находясь в директории проекта выполните:

```sh
podman compose up -d --build
```
